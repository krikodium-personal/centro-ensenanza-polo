# Centro de Enseñanza de Polo

Página de presentación del centro de enseñanza de la Asociación Argentina de Polo: equipo, programa por niveles, certificaciones, inscripción a la plataforma online y calendario de seminarios presenciales.

Sitio estático (un solo `index.html`, sin build). Diseño basado en el sistema de estilo "Anthropic".

**Estado: borrador.** Fechas, programas de seminarios, precios y varios textos son de ejemplo y están pendientes de confirmación. El formulario de registro todavía no envía datos.

Para verlo en local: `python3 -m http.server` y abrir http://localhost:8000.
